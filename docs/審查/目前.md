## 步驟

### 1.（網頁 GPT）第一個 commit：CI 只在預設分支發 Release

### 2.（網頁 GPT）程式修正，依序每項一個 commit
- a. **PowerShell 卡住不再讓掃描永遠不結束**（`MenuScanner.cs` FindPackages）：讀輸出要有整體逾時（約 30 秒）；逾時就 `Kill()` PowerShell、`Log.Write` 記一行，繼續用登錄檔取得的結果。正常情況下結果與現在相同。
- b. **全域錯誤處理**（`Program.cs`）：加 `Application.SetUnhandledExceptionMode(CatchException)`、`Application.ThreadException`、`AppDomain.CurrentDomain.UnhandledException`，寫入 log（`Log.Write` + `Log.Save`）並顯示中文訊息「發生錯誤，詳情請按『開啟記錄檔』」。`MainForm.CopyClsid` 的 `Clipboard.SetText` 包 try/catch，失敗只在狀態列顯示「複製失敗，剪貼簿被其他程式占用」。
- c. **系統程式改用完整路徑**：`powershell.exe` → `Path.Combine(Environment.SystemDirectory, @"WindowsPowerShell\v1.0\powershell.exe")`；`notepad.exe` → `Path.Combine(Environment.SystemDirectory, "notepad.exe")`；`explorer.exe` → `Path.Combine(Environment.GetFolderPath(Environment.SpecialFolder.Windows), "explorer.exe")`。全專案搜尋確認沒有其他只給檔名的 `Process.Start`。
- d. **重新啟動檔案總管只動殼層**（`MainForm.RestartExplorer`）：用 `GetShellWindow` + `GetWindowThreadProcessId` 找殼層 PID，只結束那一個（找不到就退回目前做法但只限同 session：`p.SessionId == Process.GetCurrentProcess().SessionId`）。等待與重啟放到 `Task.Run`，按鈕期間設為忙碌；每 500ms 檢查殼層視窗是否回來，最多 10 秒，仍沒有才自己啟動 explorer。完成後狀態列顯示結果。
- e. **提權流程不凍結、失敗有提示**（`BlockList.RunMachineElevated` 與呼叫處）：改成 async（`await Task.Run(() => p.WaitForExit())`）；`HideForAllUsersAsync` 失敗或取消時顯示「沒有完成（已取消或權限不足）」。`RunMachineCommand` 的 catch 把例外訊息寫到 log 檔（提權行程自己 `Log.Write`+`Log.Save`，注意它和主程式同一個 log 檔，改成**追加**一行即可，不要覆蓋）。
- f. **字型不再每次 new**（`MainForm.OnItemChecked`）：建立 `regularFont`、`boldFont` 兩個欄位重複使用，表單關閉時釋放。
- g. **套用一半失敗的訊息**（`MainForm.ApplyAsync`）：逐項 try/catch，最後一次顯示「成功 N 項，失敗 M 項：<項目名稱>」，失敗的寫進 log。

- 回報：各 commit hash、最後一個 Actions run id 與 artifact 名稱。不合併預設分支。

### 3.（FX）試用
下載第 2 步最後 run 的 artifact（`ModernMenuManager.exe`），放到 `D:\APP\ModernMenuManager\`（或任何非下載資料夾）執行：
1. 開啟後自動掃描完成，清單與 v0.1.2 相同（項目數相同）。不同 → 停，回報。
2. 取消勾選一個不重要的項目（例如 AMD Software）→ 套用 → 選「是」重新啟動檔案總管：工作列消失後 10 秒內回來，**沒有多跳出資料夾視窗**，右鍵選單裡該項消失。
3. 再打勾恢復 → 套用 → 重啟：該項回來。
4. 右鍵某項 →「複製 CLSID」，貼到記事本確認有內容。
5. 「開啟記錄檔」能打開記錄。
任一步不正常 → 停，把狀態列文字和記錄檔最後 20 行貼回來。
